# Source Evidence Summary

## Phoenix (`/tmp/phoenix/src/phoenix/trace/`)
- `schemas.py`: `SpanContext(trace_id, span_id)`, `SpanKind(TOOL, LLM, AGENT, RETRIEVER, EVALUATOR, GUARDRAIL)`, `SpanEvent(name, timestamp, attributes)`, `SpanException`
- `otel.py`: `coerce_otlp_span_attributes()` — OTEL is internal representation, not export format
- `session.py`: `Session` links spans to conversations
- `db/insertion/span.py`: spans persisted with full attributes
- **Conclusion**: Phoenix is an evidence plane. Trace = temporal + semantic + queryable.

## Ragas (`/tmp/ragas/src/ragas/metrics/`)
- `_answer_correctness.py`: `CorrectnessClassifier(PydanticPrompt)` — LLM-as-judge with TP/FP/FN classification
- `base.py`: `MetricWithLLM`, `MetricWithEmbeddings`, `SingleTurnMetric` — metric contract
- `llms/adapters/`: `litellm.py`, `instructor.py` — provider-agnostic LLM for evaluation
- **Conclusion**: Ragas is an evaluator plane. Metric + LLM + embeddings = evaluation. No verifier separation.

## SWE-agent (`/tmp/SWE-agent/sweagent/`)
- `types.py`: `StepOutput(query, thought, action, output, observation, execution_time, tool_calls, state)`, `Trajectory = list[TrajectoryStep]`
- `agent/agents.py`: `DefaultAgent` with `AbstractModel` + `ToolHandler`
- `agent/hooks/abstract.py`: `AbstractAgentHook` with lifecycle interception points
- `environment/`: `SWEEnv` via swe-rex (separate execution layer)
- **Conclusion**: SWE-agent has agent↔environment boundary + trajectory recording + lifecycle hooks. No durability.

## Pydantic AI (`/tmp/pydantic-ai/pydantic_graph/`)
- `__init__.py`: `GraphBuilder`, `GraphRun`, `BaseNode`, `Step`, `Decision`, `Join` — generic graph execution
- `durable_exec/`: DBOS, Prefect, Temporal backends
- **Conclusion**: Graph is generic orchestration primitive. Durable execution is backend-agnostic. These are separate concerns.

## Agno/Phidata (`/tmp/phidata/libs/agno/`)
- Structure: `agent/`, `team/`, `workflow/`, `os/` (Agent OS), `vectordb/`, `knowledge/`, `tracing/`, `guardrails/`
- `agno/agent/agent.py` not read in depth
- **Conclusion**: Multi-layer architecture (Agent → Team → Workflow → OS). Needs deeper study.
