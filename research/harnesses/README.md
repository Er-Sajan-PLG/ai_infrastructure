# Agent Harnesses

> **Status: no entries yet.** This directory is a declared research category (charter §2, ADR-0001). Nothing here has been studied or implemented.

## What it is

Execution environments, coding-agent harnesses, sandboxes, terminal and filesystem access, browser automation, context management, task lifecycle, checkpointing, recovery, reproducibility.

## Why it exists

A model is not an agent until something gives it an environment, tools, and a lifecycle. This is where reliability and safety are decided in practice.
