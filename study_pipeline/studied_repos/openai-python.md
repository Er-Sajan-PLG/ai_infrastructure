## What this report cannot tell you

These are limits of the method, not of the studied project. Read them
before drawing conclusions from the sections below.

- **Dependency count is declared, not resolved.** It counts requirement
  strings in root manifests. Nothing was fetched, so a directive with 14
  declared dependencies may install 60 packages.
- **Test count is files, not tests.** Counting actual tests requires
  running them, which the pipeline does not do.
- **Pattern detection matches names and manifests.** A pattern
  implemented across files without a directory named after it will be
  missed entirely. Confidence labels the evidence, not the importance.
- **Nothing here is a judgement of quality.** A directory being present
  says nothing about whether the code inside it is good.

### STRONG (4)

*Two independent lines of evidence (multiple module-bearing directories, or a directory plus a declared dependency).*

#### Evaluation / benchmarking harness — `evaluation`

**Category:** `evaluation`

**Evidence** (directory or manifest evidence):

- `src/openai/types/evals/`
- `src/openai/resources/evals/runs/`

**Limitation:** Cannot tell a maintained evaluation suite from a stale script directory. Check the commit dates before adopting the design.

#### Safety / guardrails — `guardrails`

**Category:** `guardrails`

**Evidence** (directory or manifest evidence):

- `src/openai/resources/safety/`
- `src/openai/types/safety/`

**Limitation:** A validation module frequently validates request SHAPE, not model output. Conflating the two is the common misreading.

#### Retrieval / vector search — `retrieval`

**Category:** `retrieval`

**Evidence** (directory or manifest evidence):

- `src/openai/resources/vector_stores/`
- `src/openai/types/vector_stores/`

**Limitation:** Presence of a retrieval directory says nothing about the algorithm, the index type, or whether it is wired into anything. Read the modules to establish that.

#### Tool / function registry — `tool-registry`

**Category:** `tools`

**Evidence** (directory or manifest evidence):

**Limitation:** Cannot distinguish a decorator-based registry from a plain dict of callables, which are very different designs.
